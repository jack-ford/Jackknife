# Opening books

`8moves_v3.pgn` is the unzipped `8moves_v3.pgn.zip` from
[official-stockfish/books](https://github.com/official-stockfish/books), released
under CC0 1.0 (see `LICENSE`). It holds 34,700 balanced eight-move (16-ply) lines
used by Stockfish's testing framework.

SHA-256: `5835239f88cc2c7511b177c32392a69f3ede21819cf0616f80a7f907cd21d17e`

Other PGN books from that repository load the same way once unzipped. Its EPD
books list positions without the moves that reach them, so they cannot be used
as opening books.
